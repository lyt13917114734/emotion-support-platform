# 实验二平台开发规格

状态：本地前端试跑版，尚不能用于正式被试采集。材料配置与测量流程更新：2026-09-10。当前测量配置、时点及迁移规则以《测量字段与流程.md》为准。

## 已确定的设计

- 单因素被试内：A 情绪识别辅助，B 策略供给辅助。不是 A 与 A+B。
- 8 项正式任务分两个区组，每区组同一辅助连续 4 项，每题后即时测量。
- 2 项练习分开，分别位于对应区组之前。练习后先进入正式任务过渡页，再完成区组pre状态记录，随后进入第一项正式任务。
- 任务入口 → 简版知情同意说明 → 完整版阅读确认 → 信息登记 → 前测 → 总指导语 → 第一条件练习 → 正式过渡/区组开始状态 → 正式1/目标达成感 → 正式2/状态/目标达成感/作答检查 → 正式3/目标达成感 → 正式4/状态/目标达成感 → 区组AI辅助作用、采纳及整合成本 → 区组AI辅助信息评价 → 统一过渡 → 第二条件指导语与练习 → 同结构的第二正式区组 → 总体评价 → 完成。
- 练习本身不设任务后评价或以练习为回忆对象的状态评价。练习回复明确标记，不能混入正式结果。
- 页面、布局、按钮与回应要求不随 A/B 改变；B条件任务评价额外显示研究者指定的策略分类单选题。
- 登记入组年龄保留18岁及以上，不设上限；年龄仅记录四个互不重叠区间，不推算具体年龄。性别仅“女”“男”，所有选项默认留空。旧记录需补选缺失或无效性别、年龄后恢复原进度，不重新随机。正式知情同意签署仍在平台外完成，登记不重复收集签署或试跑同意状态。

## 一个平台，四种平衡顺序

| 版本 | 区组一 | 区组二 |
| --- | --- | --- |
| AX_BY | A + X | B + Y |
| AY_BX | A + Y | B + X |
| BX_AY | B + X | A + Y |
| BY_AX | B + Y | A + X |

X/Y 各 4 个事件，每人每事件只呈现一次。当前 X 为 C01、C09、C14、C39，Y 为 C11、C22、C23、C35。区组内带种子随机洗牌，恢复时不重新随机。练习材料 C04/C26 的顺序另行随机保存；练习辅助方式跟随当前区组。

事件文本改写自 EmpatheticDialogues 中讲述者材料，并保留候选编号与原始 `source_id` 供来源回溯；中文文本以研究者确认的事件库为准。固定 AI 卡片采用 A“主要情绪—文本线索—情绪判断”和 B“共情参与—认知重评—使用注意”的三段结构，每张卡片为 110—125 字，同一事件 A/B 字数差不超过 5%。材料集与辅助条件通过四种顺序交叉平衡，因此正式事件不永久绑定某一种辅助。上述材料已确认用于平台接入与试跑；正式采集前仍需完成材料强度、难度和 AI 输出的预测试及最终核查。

本地试跑允许研究者选择版本或随机预览，不保证跨设备的样本配额。正式版本接受研究人员发放的匿名研究编号（1个英文字母加3位数字，例如 D001）；编号首次进入时，由后端依据四种顺序当前已分配人数自动选择人数最少的顺序，并在并列时随机分配。分配与会话在同一数据库事务内保存，同一编号不得重复创建，恢复时沿用原分配，不因刷新、退出、速度或结果重抽。退出与失访另记，不根据结果临时调换条件。

## 单个任务

匿名头像与编号 → 负性事件 → 点击AI提示展开固定卡片 → 至少展开一次后启用开始回复 → 出现回复框 → 有效发送 → 按流程显示状态记录（仅区组第2/4项）→ 该题即时评价 → 下一条。

允许拒绝、部分采用或修改AI建议；不生成完整回复。开始回复后仍可查看卡片。总指导语只讲操作，不提前展示另一条件的卡片或策略示例。

`inputMS = 首次有效发送时间 - 首次点击开始回复时间`。包括构思、输入、修改和再次查看卡片，不包括开始回复前的阅读、发送后的量表。无效发送不结束计时；重试不重置；页面不显示计时。刷新恢复原时间与草稿，同时标记中断，不能声称中断没有影响。

## 测量与材料边界

- 当前平台已撤下原创虚构示例，接入 2 条练习、8 条正式事件及其 20 张固定 AI 卡片；来源与审核状态随材料版本写入导出数据。
- 前测当前为AI信任、疲惫、压力、情绪效价和唤醒5题；区组内状态在每区组正式任务开始前、第2项完成后和第4项完成后各测1次。所有滑条均为1—7整数，初值null，全部必答。
- 每项正式任务后呈现3道目标达成感题；B条件同页另有1道策略分类题。
- AI辅助作用与采纳3题及AI信息整合成本3题均为区组层级测量，只在每区组第4项任务的状态记录和目标达成感评价之后出现1次。
- 区组状态每次包含疲惫、压力、维持专注努力、思维清晰度和情绪消耗5题；保存文档规定的认知清晰度反向分及认知资源消耗均分。
- 量表配置独立，不因界面实现宣称量表已获得信效度验证，也不冒称为NASA-TLX。
- 过渡时长、回复字数阈值是待试跑确认的参数，不声称4题必然诱发疲劳。

## 保存与导出

本地适配器仅写当前浏览器localStorage，不上传。清除浏览器数据、更换设备或禁用存储会影响恢复。保存失败阻止前进。不能伪装研究者已收到数据。

导出完整JSON、trial CSV、测量长表CSV、盲评回复CSV。记录协议/材料/量表版本、随机种子、分配来源、会话ID、被试号、阶段、题序、事件ID、条件、卡片、回复、评分、操作时间、inputMS及中断标记。盲评仅导出非识别性编码、事件与回复，不暴露条件、顺序或AI卡片。

正式后端需分配、恢复、幂等提交及受保护研究者导出。本地版不能可靠实现身份认证、防篡改、集中收数和全样本平衡。

本地试跑使用浏览器Web Locks限制同一网址一个活跃标签页，避免两页同时写入。保存失败保留候选状态，重试不改变首次有效发送时间；应急JSON包含未保存操作。非盲trial CSV包含response_id，可与盲评结果回并。材料/量表版本不匹配时拒绝直接恢复，更新配置必须同步更新版本号。

流程或题目版本更新保留明确兼容边界：旧试跑测量整体归档，新测量不继承旧分数并从前测重新开始；参与者身份、分配、事件顺序和已提交回复保留。测量CSV以 `record_status` 区分草稿和提交，空题保持空白。暂存退出后提供本机继续入口，恢复原会话和原顺序，不重新分配。

## GitHub 与上线

仅上传本项目代码和获准公开的演示材料，不上传原始数据、被试信息、私密材料、访问码映射或密钥。GitHub Pages 可托管静态前端，不提供本研究的数据后端。正式采集前核查访问稳定性、权限、知情同意、隐私及数据保留。本轮不创建远程仓库、不推送、不部署。

## 验证要求

四版本分配正确；每会话2练习+8正式；练习分开且无评价；每区组准确生成pre/mid/post三次状态和区组末一次整合体验；第2/4项先状态后任务评价；正式每题评价一次；未看卡片不可回复；无效发送不结束计时；重复提交幂等；刷新保留计划/草稿/首次计时；保存失败不前进；练习可排除；CSV可识别区组、条件、任务位置、测量时点及已完成正式任务数；CSV防公式注入；未接后端不能开启正式模式。
