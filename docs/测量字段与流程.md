# 当前测量字段与流程

更新：2026-09-11。题干、端点、分类选项以《实验二平台全部测量题目_按测量阶段整理（final）》为准，配置集中在 `lib/measurements.ts`，不因此宣称量表已获得信效度验证。协议版本 `E2-local-demo-20260911-v6`；测量版本 `researcher-measurements-20260911-v5`；会话schema为3。

## 流程

前测5题 → 原总指导语 → 第一条件练习 → 正式任务过渡 → 区组开始状态 → 正式任务1/目标达成感 → 正式任务2 → 第2项后状态 → 目标达成感 → 区组1作答检查 → 正式任务3/目标达成感 → 正式任务4 → 第4项后状态 → 目标达成感 → 区组1 AI辅助作用、采纳与信息整合成本 → 区组1 AI辅助信息评价 → 原3分钟过渡 → 第二条件指导语与练习 → 按相同结构完成第二区组 → 总体评价 → 完成。

共38个流程节点，其中22个测量页面。正式任务共8项，每项3道目标达成感题，B条件另外1道策略分类题。区组状态每次5题，区组AI辅助使用评价每次6题。保留文档明确要求继续沿用的5题前测后，总计91个原始作答字段：86个数字评分与5个分类答案。练习不追加任务后评价或状态评价。

`baseline_emotional_statue`保留研究者给定拼写，不擅自改字段。前后AI信任题使用相同题干和端点。登记继续使用现有生成式AI使用经验题，不增加尚未定稿的频率、熟练程度题。

策略分类保存 emotional_engagement / cognitive_engagement / combined / neither；分别为情感参与、认知参与、两种方式结合使用、均未采用。A条件不创建此作答字段，宽表中对应列为空。

总体偏好保存 emotion_support / strategy_support / no_preference；分别为情绪识别辅助、策略供给辅助、两者相近没有明显偏好。分类题不用数值滑条，不计入均分。

## 作答与保存

所有可见题必答。滑条只接受1—7整数，初始null，无默认滑块；分类题初始也为null。完整作答后才启用下一步。作答检查要求区组1选2、区组2选6；其他有效数值也允许继续，不告知正误。passed标记提交前为null，提交后为boolean，不混入心理指标。

每次修改自动本地保存；上一页、浏览器返回、刷新和暂存恢复均沿用原会话及分配。量表重新提交更新同一条记录及updated_at，保留首次提交时间，不产生重复记录。已发送回复只读回看，继续不会再次计时或重复发送。

文档规定的关联元数据为 participant_id、schedule_order、block_index、condition、material_set、event_id、task_position、measurement_timepoint、created_at、updated_at。measurement_timepoint使用experiment_pre、block_start、after_task_2、after_task_4、task_post、block_end和experiment_post；登记信息不属于正文测量页。为兼容既有本地数据，同时保留schedule_id、block_id、material_id、measurement_time和completed_formal_tasks字段。

record_status区分not_started/draft/submitted。本地JSON按initial_measurement、task_evaluations、block_state、integration_cost、block_evaluation、overall_evaluation保存关联结构；原surveyDrafts用于页面恢复。测量CSV输出全部计划项目，未答单元格为空，不填0。JSON未答保留null。盲评回复导出保持不暴露条件的原有规则。

保存及导出 cognitive_clarity_reversed（8 - cognitive_clarity）、cognitive_resource_depletion_mean（focus_maintenance_effort与cognitive_clarity_reversed均分）、goal_attainment_mean、integration_cost_mean和ai_trust_change（ai_trust_post - ai_trust_pre）。组成题目均有效时才计算，否则为null；原始答案保持不变。

## 旧记录

2026-09-11按final文档同步题目后，上一版v5/v4测量以及更早的已知试跑记录升级时，将旧测量草稿、提交记录和旧流程整体归档到legacyMeasurements，新测量从前测重新开始。参与者编号、登记信息、随机分配、事件顺序、已提交回复及其计时继续保留，所有新测量标记timing_status=legacy_session_recollection，不得作为原定时点数据使用。

正式任务CSV现仅导出8项正式任务；练习原始回复和计时仍保留在完整JSON作为流程记录，不进入正式统计、盲评或任务评价。不会为新练习生成任何评价答案。

支持已知旧测量版本：旧量表草稿/提交/页面时间归档至legacyMeasurements，不复制旧分数到新题；保留参与者资料、原分配、事件顺序和已提交回复。重新从新前测开始。所有这种迁移会话的新测量标记timing_status=legacy_session_recollection，提醒补答并不代表原时点的主观状态，不能与按新流程正常完成的scheduled记录混用。

无法识别的版本或损坏记录不强制覆盖。保存失败时停止操作，保留应急导出。仅本地保存，尚未实现后端集中收数。
